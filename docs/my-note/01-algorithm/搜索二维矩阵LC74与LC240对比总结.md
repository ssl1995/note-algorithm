# 搜索二维矩阵：LC74 与 LC240 对比总结
## 一、题目条件差异（决定解法的根本原因）
**LC74 搜索矩阵**：
1. 每行从左到右非严格递增；
2. **每行的第一个整数大于前一行的最后一个整数**。
**LC240 搜索二维矩阵II**：
1. 每行从左到右递增；
2. 每列从上到下递增；
3. **行与行之间没有衔接关系**（下一行首元素可以小于上一行末元素）。
核心差异：LC74 的条件2 保证了整个矩阵按行拼接后是一个**全局有序的一维数组**；LC240 只有局部单调性（行、列各自有序），拼接起来**不是全局有序**。
## 二、解法对比
### LC74：展开成一维数组做二分查找
因为全局有序，把 m×n 矩阵逻辑上当作长度为 m*n 的一维数组，直接标准二分：
```java
public boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length;
    int n = matrix[0].length;
    // 一维数组范围：[0, mn-1]
    int left = 0;
    int right = m * n - 1;
    // 闭区间，必须有 =
    while (left <= right) {
        int mid = left + (right - left) / 2;
        // 转成二维坐标
        int row = mid / n; // 注意：除以列数 n，不是行数 m
        int col = mid % n;
        if (matrix[row][col] < target) {
            left = mid + 1;
        } else if (matrix[row][col] > target) {
            right = mid - 1;
        } else {
            return true;
        }
    }
    return false;
}
```
关键点：
- 一维下标 mid 转二维坐标：`row = mid / n`，`col = mid % n`（n 是列数）；
- 闭区间写法 `left <= right`，收缩时 `mid ± 1`；
- 时间复杂度 O(log(mn))，空间 O(1)。
### LC240：从右上角（或左下角）开始的"排除法"搜索
因为不是全局有序，无法整体二分。利用行列各自的单调性，从**右上角**出发，每一步排除一整行或一整列：
```java
public boolean findNumberIn2DArray(int[][] matrix, int target) {
    if (matrix == null || matrix.length == 0) {
        return false;
    }
    // 从右上角开始：比 target 大就往左移（排除一列），比 target 小就往下移（排除一行）
    int i = 0;
    int j = matrix[0].length - 1;
    while (i < matrix.length && j >= 0) {
        if (matrix[i][j] < target) {
            i++; // 当前行剩余元素都 <= 当前值 < target，排除整行
        } else if (matrix[i][j] > target) {
            j--; // 当前列剩余元素都 >= 当前值 > target，排除整列
        } else {
            return true;
        }
    }
    return false;
}
```
关键点：
- 起点必须选**右上角或左下角**：这两个位置一个方向递增、另一个方向递减，比较后能确定唯一的排除方向；
- 不能选左上角或右下角：这两个位置两个方向同增或同减，比较后无法排除任何行列，利用不到单调性；
- 时间复杂度 O(m+n)，空间 O(1)。
## 三、经验总结
1. **先看条件再选算法**：二维矩阵搜索题的第一步是判断矩阵是否"全局有序"。有"每行首元素大于上一行末元素"→ 全局有序 → 一维二分；只有"行列各自有序"→ 角落排除法。
2. **全局有序套二分模板**：本质是一维二分，只是多了一步 `mid → (mid/n, mid%n)` 的坐标映射，二分的区间写法（开/闭区间）照常遵守。
3. **局部有序用角落排除法**：从右上/左下角出发，每步比较都能排除一行或一列，把 O(mn) 暴力降到 O(m+n)。选角原则：站在该角上，两个移动方向必须是"一增一减"。
4. **LC240 也可对每行做二分**（O(m·log n)），但角落排除法 O(m+n) 更优且实现更简洁，优先掌握。
5. **LC74 也可以退化为两次二分**（先二分定位行、再在行内二分），但一维展开写法最短，不易出错。
## 四、速查表
| 维度 | LC74 搜索矩阵 | LC240 搜索二维矩阵II |
|---|---|---|
| 有序性 | 全局有序（行间有衔接） | 行列各自有序（行间无衔接） |
| 核心思路 | 展开成一维数组 + 二分查找 | 右上角起点，逐步排除行/列 |
| 坐标映射 | row=mid/n, col=mid%n | 无，直接移动 i、j |
| 时间复杂度 | O(log(mn)) | O(m+n) |
| 空间复杂度 | O(1) | O(1) |
| 易错点 | 除以列数 n 而非行数 m；闭区间要带 = | 起点选错角（左上/右下无法排除）；忘记判空 |
