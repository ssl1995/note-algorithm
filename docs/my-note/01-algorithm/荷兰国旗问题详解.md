# 荷兰国旗问题（Dutch National Flag Problem）详解
> 三向划分（3-way Partition）的经典应用，快速排序的核心优化
---
## 一、问题起源
**荷兰国旗**：红、白、蓝三色横条
```
┌─────────┬─────────┬─────────┐
│   红    │   白    │   蓝    │
│    0    │    1    │    2    │
└─────────┴─────────┴─────────┘
```
**问题**：给定一个包含 0、1、2 的数组，**原地**排序，使得：
- 所有 0 排在前面（红色）
- 所有 1 排在中间（白色）
- 所有 2 排在后面（蓝色）
**约束**：只能遍历一次，常数空间
---
## 二、核心思想：三指针划分
### 2.1 指针定义
| 指针 | 含义 | 初始化 | 移动条件 |
|------|------|--------|---------|
| `a` | 下一个 0 应该放置的位置 | `l`（左边界）| 遇到 `< v` 的元素 |
| `b` | 下一个 2 应该放置的位置 | `r`（右边界）| 遇到 `> v` 的元素 |
| `i` | 当前遍历位置 | `l`（左边界）| 每次循环都可能移动 |
### 2.2 区间划分（关键！）
```
[ l, a )  : 已确定的 < v 区域（红色/0）
[ a, i )  : 已确定的 = v 区域（白色/1）
[ i, b ]  : 未探索区域（待处理）
( b, r ]  : 已确定的 > v 区域（蓝色/2）
```
**注意**：`[i, b]` 是**闭区间**，`b` 是未探索区域的右边界
---
## 三、代码实现与指针开闭分析
```java
private void partition(int[] nums, int l, int r, int v) {
    int a = l;      // [l, a) 是 < v 区域
    int b = r;      // (b, r] 是 > v 区域，[i, b] 是未探索区域
    int i = l;      // 当前遍历位置
    while (i <= b) {  // 关键：i <= b，因为 [i, b] 是闭区间
        if (nums[i] < v) {
            swap(nums, a++, i++);  // 交换到 < v 区域，a 和 i 都右移
        } else if (nums[i] > v) {
            swap(nums, b--, i);    // 交换到 > v 区域，b 左移，i 不动！
        } else {
            i++;                    // 等于 v，i 右移
        }
    }
}
```
### 3.1 为什么 `i <= b` 而不是 `i < b`？
| 条件 | 含义 | 结果 |
|------|------|------|
| `i <= b` | `[i, b]` 闭区间，包含 `b` | 遍历到 `b` 位置才停止 |
| `i < b` | `[i, b)` 左闭右开 | 会漏掉 `b` 位置的元素 |
**例子**：`nums = [2, 0, 1]`，`v = 1`
```
初始: a=0, b=2, i=0
      [2, 0, 1]
       ↑     ↑
       i     b
i=0: nums[0]=2 > 1, swap(b=2, i=0) → [1, 0, 2], b=1
      [1, 0, 2]
       ↑  ↑
       i  b
i=0: nums[0]=1 = 1, i++ → i=1
      [1, 0, 2]
          ↑
          i,b
i=1: nums[1]=0 < 1, swap(a=0, i=1) → [0, 1, 2], a=1, i=2
      [0, 1, 2]
             ↑
             i (i=2 > b=1, 循环结束)
```
如果 `i < b`：当 `i=1, b=1` 时循环结束，`nums[1]=0` 没被处理！
### 3.2 为什么 `nums[i] > v` 时 `i` 不动？
```java
swap(nums, b--, i);  // i 不增加！
```
**原因**：从 `b` 位置交换过来的元素是**未探索的**，需要重新检查。
**例子**：`nums = [1, 2]`，`v = 1`
```
初始: a=0, b=1, i=0
      [1, 2]
       ↑  ↑
       i  b
i=0: nums[0]=1 = 1, i++ → i=1
      [1, 2]
          ↑
          i,b
i=1: nums[1]=2 > 1, swap(b=1, i=1) → [1, 2]（自己和自己交换）, b=0
      如果 i++，i=1 > b=0，循环结束，但 nums[1]=2 没被正确处理！
      正确做法：i 不动，继续检查 nums[1]（现在是 2，但 b 已左移）
      实际上这里自己和自己交换，i=1 > b=0，循环结束
```
**更明显的例子**：`nums = [2, 1]`，`v = 1`
```
初始: a=0, b=1, i=0
      [2, 1]
       ↑  ↑
       i  b
i=0: nums[0]=2 > 1, swap(b=1, i=0) → [1, 2], b=0
      [1, 2]
       ↑  ↑
       i  b (i=0, b=0)
如果 i++：i=1 > b=0，循环结束，但 nums[0]=1 没被检查！
正确：i 不动，继续检查 nums[0]=1 = 1，i++ → i=1 > b=0，结束
```

## 五、指针初始化的开闭问题
### 5.1 三种常见写法对比
| 写法 | 初始化 | 循环条件 | 区间定义 | 特点 |
|------|--------|---------|---------|------|
| **左闭右闭** | `a=l, b=r, i=l` | `i <= b` | `[l,a) < v`, `[a,i) = v`, `[i,b] ?`, `(b,r] > v` | **推荐**，直观 |
| 左闭右开 | `a=l, b=r+1, i=l` | `i < b` | `[l,a) < v`, `[a,i) = v`, `[i,b) ?`, `[b,r] > v` | 需调整 `b` 初始值 |
| 双指针 | `a=l-1, b=r+1, i=l` | `i < b` | `[l,a] < v`, `[a+1,i) = v`, `[i,b) ?`, `[b,r] > v` | 边界易错 |
### 5.2 推荐写法：左闭右闭
```java
int a = l;      // [l, a) 是 < v
int b = r;      // (b, r] 是 > v，[i, b] 是未探索
int i = l;
while (i <= b) {  // 闭区间，包含 b
    // ...
}
```
**优点**：
- `b` 直接指向未探索区域的右边界
- 循环条件 `i <= b` 自然
- 不需要 `+1` 或 `-1` 调整

## 六、与快速排序的关系
### 6.1 快速排序的划分
```java
// 二路划分（Lomuto）
int partition(int[] nums, int l, int r) {
    int pivot = nums[r];
    int i = l - 1;
    for (int j = l; j < r; j++) {
        if (nums[j] < pivot) {
            swap(nums, ++i, j);
        }
    }
    swap(nums, i + 1, r);
    return i + 1;
}
// 三路划分（荷兰国旗）
void partition3(int[] nums, int l, int r, int v) {
    int a = l, b = r, i = l;
    while (i <= b) {
        if (nums[i] < v) swap(nums, a++, i++);
        else if (nums[i] > v) swap(nums, b--, i);
        else i++;
    }
}
```
### 6.2 为什么快速排序需要三路划分？
| 场景 | 二路划分 | 三路划分 |
|------|---------|---------|
| 大量重复元素 | 退化为 O(n²) | 保持 O(n log n) |
| 例子 `[1,1,1,1,1]` | 每次只排好一个 | 一次划分全部完成 |

## 七、与二分查找的联系
### 7.1 二分查找的区间思想
荷兰国旗问题和二分查找都体现了**区间划分**的思想：
| 算法 | 区间划分 | 核心操作 |
|------|---------|---------|
| 二分查找 | `[l, mid)` 和 `(mid, r]` | 根据目标值选择左/右区间 |
| 荷兰国旗 | `[l,a)`, `[a,i)`, `[i,b]`, `(b,r]` | 根据元素值交换到对应区间 |
### 7.2 边界处理的相似性
**二分查找（左闭右闭）**：
```java
int binarySearch(int[] nums, int target) {
    int l = 0, r = nums.length - 1;  // [l, r] 闭区间
    while (l <= r) {                  // l <= r
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```
**荷兰国旗（左闭右闭）**：
```java
int a = l, b = r, i = l;            // [i, b] 闭区间
while (i <= b) {                     // i <= b
    // ...
}
```
**共同点**：
- 都使用**闭区间**定义边界
- 循环条件都是 `<=`（因为闭区间包含边界）
- 都需要仔细处理边界，避免死循环或遗漏
### 7.3 快速选择（QuickSelect）：二分 + 划分
LC215 数组中的第 K 个最大元素，结合了快速排序的划分和二分查找的思想：
```java
public int findKthLargest(int[] nums, int k) {
    int l = 0, r = nums.length - 1;
    int target = nums.length - k;  // 第 K 大 = 第 n-k 小
    while (l <= r) {
        int p = partition(nums, l, r);  // 荷兰国旗划分
        if (p == target) return nums[p];
        else if (p < target) l = p + 1;  // 去右边找
        else r = p - 1;                   // 去左边找
    }
    return -1;
}
```
**核心思想**：
1. 用荷兰国旗划分，确定 pivot 的最终位置
2. 根据 pivot 位置与 target 的关系，选择左/右区间继续查找
3. 类似二分查找，每次排除一半元素

## 八、更多例子
### 8.1 例子：全相同元素
**输入**：`nums = [1, 1, 1, 1]`，`v = 1`
| 步骤 | `i` | `a` | `b` | `nums` | 操作 |
|------|-----|-----|-----|--------|------|
| 初始 | 0 | 0 | 3 | `[1,1,1,1]` | - |
| 1 | 0→1 | 0 | 3 | `[1,1,1,1]` | `nums[0]=1=1`，`i++` |
| 2 | 1→2 | 0 | 3 | `[1,1,1,1]` | `nums[1]=1=1`，`i++` |
| 3 | 2→3 | 0 | 3 | `[1,1,1,1]` | `nums[2]=1=1`，`i++` |
| 4 | 3→4 | 0 | 3 | `[1,1,1,1]` | `nums[3]=1=1`，`i++` |
| 结束 | 4 | 0 | 3 | `[1,1,1,1]` | `i=4 > b=3` |
**结果**：`[1, 1, 1, 1]`，无需交换，时间 O(n)

## 九、记忆口诀
```
荷兰国旗三指针，a b i 要记清：
a 指小于区末尾，b 指大于区开头，
i 遍历未探索区，i <= b 才停手。
小于交换 a i 走，大于交换 b 左移，
等于直接 i 前进，大于 i 要停留！
```
