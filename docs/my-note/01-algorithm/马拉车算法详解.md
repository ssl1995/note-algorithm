# 马拉车算法（Manacher's Algorithm）详解

> 求最长回文子串的 O(n) 算法，面试加分项

---

## 一、为什么需要马拉车算法？

| 方法 | 时间复杂度 | 问题 |
|------|-----------|------|
| 暴力法 | O(n³) | 枚举所有子串，判断回文 |
| 中心扩展 | O(n²) | 奇偶回文中心不同，需分情况讨论 |
| 动态规划 | O(n²) | 空间复杂度高 |
| **马拉车** | **O(n)** | **统一处理奇偶，利用对称性优化** |

---

## 二、核心思想：预处理 + 对称性利用

### 2.1 预处理：统一奇偶回文

**问题**：回文有奇偶之分
- 奇数回文：`"aba"`，中心是 `b`
- 偶数回文：`"abba"`，中心在两个 `b` 之间

**解决**：插入特殊字符 `#`，统一为奇数回文

```
原串:  "cabac"
转换:  "#c#a#b#a#c#"

原串:  "abba"
转换:  "#a#b#b#a#"
```

**规律**：长度 `n` → `2n+1`，偶数位放 `#`，奇数位放原字符

### 2.2 核心概念

| 概念 | 定义 | 例子 `#c#a#b#a#c#` |
|------|------|------------------|
| `pArr[i]` | 以 `cs[i]` 为中心的最大回文半径 | `pArr = [1,2,1,2,1,6,1,2,1,2,1]` |
| `pR` | 当前最右回文边界的**下一个位置** | 遍历到 `b` 时，`pR = 11` |
| `index` | 最近一次更新 `pR` 时的回文中心 | 遍历到 `b` 时，`index = 5` |

**关键关系**：`pR = index + pArr[index]`

## 三、算法流程（四步走）

```
for i in 0..cs.length-1:
    1. 【利用对称性】初始化 pArr[i] 的最小可能值
    2. 【中心扩展】尝试向外扩展，更新 pArr[i]
    3. 【更新边界】如果 i + pArr[i] > pR，更新 pR 和 index
    4. 【记录答案】更新最长回文信息
```

### 3.1 第一步：利用对称性初始化

```java
pArr[i] = pR > i ? Math.min(pArr[2 * index - i], pR - i) : 1;
```

**两种情况**：

| 情况 | 条件 | 含义 | 初始值 |
|------|------|------|--------|
| A | `pR <= i` | `i` 在已知回文范围外，无法优化 | `1`（自身）|
| B | `pR > i` | `i` 在已知回文范围内，可利用对称性 | `min(pArr[mirror], pR - i)` |

**情况 B 的图解**：

```
        index
          ↓
    ... [mirror ... i ...] ... pR
              ↑     ↑
           对称点   当前点

mirror = 2 * index - i
```

- `pArr[mirror]`：镜像位置的回文半径
- `pR - i`：当前位置到右边界的距离
- 取较小值：保证不超出已知范围

### 3.2 第二步：中心扩展

```java
while (i + pArr[i] < cs.length && i - pArr[i] >= 0) {
    if (cs[i + pArr[i]] == cs[i - pArr[i]])
        pArr[i]++;
    else
        break;
}
```

从初始值开始，尝试向外扩展，直到不匹配或越界。

### 3.3 第三步：更新边界

```java
if (i + pArr[i] > pR) {
    pR = i + pArr[i];
    index = i;
}
```

如果当前回文右边界超过已知最右边界，更新 `pR` 和 `index`。

### 3.4 第四步：记录答案

```java
if (pArr[i] > maxLen) {
    maxLen = pArr[i];
    centerIndex = i;
}
```

## 四、完整代码

```java
public class Solution4 {

    public String longestPalindrome(String s) {
        if (s.length() < 2) {
            return s;
        }
        
        // 1. 预处理：插入 #
        char[] cs = manacherString(s);
        int[] pArr = new int[cs.length];
        
        int pR = -1;      // 最右回文边界的下一个位置
        int index = -1;   // 最近更新 pR 的回文中心
        
        int maxLen = Integer.MIN_VALUE;
        int centerIndex = Integer.MIN_VALUE;
        
        for (int i = 0; i < cs.length; i++) {
            // 2. 利用对称性初始化
            pArr[i] = pR > i ? Math.min(pArr[2 * index - i], pR - i) : 1;
            
            // 3. 中心扩展
            while (i + pArr[i] < cs.length && i - pArr[i] >= 0) {
                if (cs[i + pArr[i]] == cs[i - pArr[i]]) {
                    pArr[i]++;
                } else {
                    break;
                }
            }
            
            // 4. 更新边界
            if (i + pArr[i] > pR) {
                pR = i + pArr[i];
                index = i;
            }
            
            // 5. 记录最长
            if (pArr[i] > maxLen) {
                maxLen = pArr[i];
                centerIndex = i;
            }
        }
        
        // 6. 转换回原串坐标
        maxLen = maxLen - 1;  // 原串长度 = 半径 - 1
        centerIndex = (centerIndex - 1) / 2;  // 原串中心
        int begin = centerIndex - (maxLen - 1) / 2;
        
        return s.substring(begin, begin + maxLen);
    }

    private char[] manacherString(String s) {
        int n = s.length();
        char[] res = new char[2 * n + 1];
        int index = 0;
        for (int i = 0; i < 2 * n + 1; i++) {
            res[i] = (i & 1) == 0 ? '#' : s.charAt(index++);
        }
        return res;
    }
}
```

## 五、举例说明

### 例子：`s = "cabac"`

**预处理**：`cs = ['#','c','#','a','#','b','#','a','#','c','#']`

| i | cs[i] | 初始化 pArr[i] | 扩展后 | pR | index | 说明 |
|---|-------|--------------|--------|-----|-------|------|
| 0 | # | 1 (pR<=i) | 1 | 1 | 0 | 自身 |
| 1 | c | 1 (pR<=i) | 2 | 3 | 1 | 扩展 `#c#` |
| 2 | # | min(pArr[0], 3-2)=1 | 1 | 3 | 1 | 对称 |
| 3 | a | min(pArr[1], 3-3)=0→1 | 2 | 5 | 3 | 扩展 `#a#` |
| 4 | # | min(pArr[2], 5-4)=1 | 1 | 5 | 3 | 对称 |
| 5 | b | min(pArr[3], 5-5)=0→1 | 6 | 11 | 5 | 扩展 `#a#b#a#` |
| 6 | # | min(pArr[4], 11-6)=1 | 1 | 11 | 5 | 对称 |
| 7 | a | min(pArr[3], 11-7)=2 | 2 | 11 | 5 | 对称+扩展 |
| 8 | # | min(pArr[2], 11-8)=1 | 1 | 11 | 5 | 对称 |
| 9 | c | min(pArr[1], 11-9)=2 | 2 | 11 | 5 | 对称+扩展 |
| 10 | # | min(pArr[0], 11-10)=1 | 1 | 11 | 5 | 对称 |

**结果**：
- `maxLen = 6`（`pArr[5] = 6`）
- 原串长度 = `6 - 1 = 5`
- 原串中心 = `(5 - 1) / 2 = 2`（字符 `b`）
- `begin = 2 - (5-1)/2 = 0`
- 返回 `"cabac"`（整个串就是回文）

## 六、复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个字符最多被访问两次（一次作为中心，一次作为扩展点）|
| 空间 | O(n) | 存储预处理后的数组和 pArr |

**为什么时间复杂度是 O(n)？**

- 内层 `while` 循环看似 O(n)，但 `pR` 单调递增
- 每次扩展都会让 `pR` 右移，总移动次数 ≤ 2n+1
- 均摊后，每个位置只被扩展常数次

## 七、记忆口诀

```
马拉车，四步走：
一插二扩三更新，四记答案五转换。

插：插入 # 统一奇偶
扩：利用对称性初始化，再中心扩展
更新：右边界 pR 和中心 index
记：记录最长半径和中心
转换：半径-1是长度，(中心-1)/2是原坐标
```
